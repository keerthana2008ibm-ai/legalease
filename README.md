# LegalEase - AI Powered Legal Document Generator

> An AI-powered platform to simplify and auto-generate legal documents.

LegalEase helps users create accurate, professional legal documents in minutes using Generative AI. It eliminates complex legal jargon and makes legal assistance accessible to everyone.

### ✨ Features
- AI-powered document generation (NDA, Rental Agreement, Employment Contract, etc.)
- Simple user input form -> Professional legal draft
- Jargon-free, legally compliant templates
- Download as PDF / DOCX
- Multi-language support

### 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask / FastAPI) / Java
- **AI Model:** IBM Granite / Watsonx.ai Foundation Model
- **Tools:** GitHub, IBM Cloud
